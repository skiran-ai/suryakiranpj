## Brand & Style

The design system projects an uncompromising vision of 2027 computing: an ambient, antigravity spatial environment built for an elite Python Full Stack & AI Systems Software Engineer. The aesthetic merges zero-gravity fluid dynamics with hyper-precise quantum telemetry HUD interfaces. It evokes intellectual dominance, bleeding-edge engineering mastery, and cinematic calm.

The core visual style is a synthesis of **Dark Mode Glassmorphism**, **Futuristic HUD Micro-Interfaces**, and **High-Contrast Cybernetics**:
- **Atmosphere:** Deep-space obsidian voids devoid of standard flat greys, layered with dynamic field gradients and sub-surface energy conduits.
- **Dimensionality:** Floating planes hovering over a 3D gravity matrix grid, marked by hairline luminous borders, quantum blurs, and spectral neon glows.
- **Sensory Resonance:** Clean, silent, lethal precision. Visual elements evoke particle accelerators, neural tensor engines, and orbit-class telemetry consoles rather than typical static web portfolios.

## Colors

The color palette operates as a photonic spectrum emerging from an absolute zero void:

- **Primary (`#00F0FF` - Neon Cyan / Quantum Core):** Primary optical focal point. Used for reactive states, terminal prompt cursors, active neural nodes, primary actions, and electromagnetic energy paths.
- **Secondary (`#8B5CF6` - Electric Violet / Tensor Field):** Spatial depth driver and sub-harmonic accent. Used for secondary interactive states, AI architecture layers, ambient focal blooms, and gradient perimeter shifts.
- **Tertiary (`#10B981` - Cyber Emerald / Matrix Pulse):** System telemetry, runtime health checks, verified execution status, and high-frequency data indicators.
- **Neutral Surface Palette:**
  - `Void Base` (`#08080C`): Infinite background canvas.
  - `Sub-orbital Surface` (`#0D0E15`): Structural backdrops and layout section wells.
  - `Glass Core` (`rgba(13, 14, 21, 0.65)`): Floating panel fills with refraction filters.
  - `Luminescent Edge` (`rgba(255, 255, 255, 0.08)` to `rgba(0, 240, 255, 0.35)`): Hairline vector dividers.
- **Text Tiers:**
  - `White Hot` (`#F8FAFC`): Primary headers, crucial values, interactive signals.
  - `Telemetry Slate` (`#94A3B8`): Body prose, parameter labels, code comments.
  - `Muted Quantum` (`#475569`): Auxiliary coordinates, background grid line indices, deactivated states.

## Typography

The typographic hierarchy establishes a rigorous division of labor across three coordinate planes:

- **Geometric Tension (Headlines - Space Grotesk):** Conveys high-velocity forward momentum, structural authority, and mathematical precision. Negative tracking tightens the visual mass of key statements.
- **Clarity & Spatial Legibility (Body - Inter):** Highly neutral and neutral-balanced text rendering designed to dissolve friction when consuming technical architecture breakdowns.
- **Instrument Telemetry & Execution (Metadata & Monospace - JetBrains Mono):** Dedicated to runtime outputs, mathematical tensor descriptions, API signatures, and HUD status labels. Upper-case labels feature generous tracking (`0.14em`) to simulate military-aerospace avionics consoles.

## Layout & Spacing

The layout is anchored on an adaptive **12-column dynamic quantum grid** suspended within an infinite 3D spatial viewport:

- **Desktop (1200px+):** 12 columns with `2.5rem` gutters and dynamic auto-centering margins capped at `1440px` max-width. Sections leverage expansive `space-3xl` gaps to instill zero-gravity detachment between cognitive modules.
- **Tablet (768px - 1199px):** 8 columns with `1.5rem` gutters and `3rem` canvas margins. Asymmetrical technical layouts fold into alternating binary panels.
- **Mobile (< 768px):** 4 columns with `1rem` gutters and `1.5rem` outer margins. HUD telemetry strips dock to fixed top and bottom glass edge rails.

Vertical cadence follows a strictly enforced 8pt spatial baseline. Macro components float with generous internal breathing room, resisting dense, claustrophobic dashboards in favor of cinematic exhibition pacing.

## Elevation & Depth

Visual hierarchy uses photonic stratification instead of classical drop shadows:

1. **Layer 0 (Singularity Void):** The dark substrate (`#08080C`), layered with an interactive WebGL 3D gravity matrix wireframe and radial ambient field drops (`#00F0FF05`, `#8B5CF608`).
2. **Layer 1 (Quantum Glass Planes):** Floating containers rendered with `backdrop-filter: blur(16px)`, background tints of `rgba(13, 14, 21, 0.65)`, and razor-thin `1px` gradient borders (`linear-gradient(135deg, rgba(0, 240, 255, 0.3) 0%, rgba(139, 92, 246, 0.1) 50%, rgba(255, 255, 255, 0.03) 100%)`).
3. **Layer 2 (Active Sub-Nodes & Overlays):** Interactive elements and code terminals gain localized micro-glows: `box-shadow: 0 0 24px -4px rgba(0, 240, 255, 0.25), inset 0 1px 1px 0 rgba(255, 255, 255, 0.15)`.
4. **Layer 3 (Beam Forefront):** Active HUD reticles, live metric tooltips, and holographic modal layers hovering with maximum optical sharpness and neon rim-lighting (`0 0 40px rgba(0, 240, 255, 0.35)`).

## Shapes

The geometric architecture avoids soft, bubble-like consumer radii in favor of **precision-machined angularity (Soft Tier 1)**:

- Standard structural panels, cards, and terminals maintain a crisp `0.25rem` (4px) or `0.5rem` (8px) corner geometry.
- Select HUD capsules and telemetry pills adopt 45-degree chamfered cuts (`clip-path: polygon(...)`) or micro-radii to evoke avionics hardware and military-grade AI processing chassis.
- Buttons and chips utilize constrained 4px rounding to ensure crisp alignment with terminal typography and tabular tensor data.

## Components

### Buttons & Interactive Triggers
- **Quantum Primary:** Solid Neon Cyan core with dark obsidian text (`#08080C`), font weight 600. On hover, produces an outward cyan ion flare (`0 0 28px rgba(0, 240, 255, 0.5)`) and shifts typography tracking outward.
- **Cyber Ghost:** Transparent surface with a 1px border gradient transitioning from Cyan to Violet. JetBrains Mono uppercase text accompanied by a terminal bracket prefix `[ RUN_EXEC ]`. Hover triggers a 10% Cyan background flood with sharp sound-dampened motion.

### Glassmorphism System Cards
- Encased in Layer 1 glassmorphism. Corners optionally feature HUD registration crosshairs (`+`) in muted quantum slate.
- Header zones contain an engineering status indicator: a pulsing 6px Cyber Emerald LED paired with real-time latency or memory allocation statistics.

### Interactive Holographic Terminal
- Obsidian black container framed by hairline borders with simulated scanline overlay (subtle 2% contrast opacity).
- Interactive command-line environment executing Python scripts, loading tensor model checkpoints, and rendering ASCII architecture diagrams.
- Active input lines signaled by a flashing `#00F0FF` block cursor.

### Telemetry HUD Chips & Badges
- Micro-pills styled with uppercase `label-caps` typography.
- Filled with 5% opacity tint of their respective status color (`#10B981` for active systems, `#00F0FF` for core skill stacks, `#8B5CF6` for experimental research models).
- Flanked by a hairline 1px border at 30% alpha.

### Form Inputs & Parameter Sliders
- Background: `rgba(8, 8, 12, 0.8)`. 1px perimeter border that transitions from `#475569` to `#00F0FF` on focus.
- Sliders for 3D gravity matrix manipulation feature neon cyan scrubbers with permanent real-time numeric readouts floating overhead in JetBrains Mono.

### Checkboxes & Toggle Switches
- Monospaced geometric toggles styled as hardware binary states (`0` / `1` or `SYS_ACTIVE` / `SYS_STANDBY`). Check markers resolve as glowing vector ticks devoid of skeuomorphic beveling.
